Colors look wrong?

Test pure red, green and blue below. If a primary color is swapped, open that tube’s WLED → Config → LED Preferences and correct the LED type or color order. TubeRoom sends RGB values; the firmware handles the strip’s wiring order. Keep WLED’s current limit enabled.

Tests briefly light the selected tube at 30% brightness, then restore it. Small shade differences can remain between the screen and LEDs.

Microphone setup

Connect reads the installed AudioReactive settings, keeps the microphone pin configuration, sets the selected tube to Send and the other compatible tubes to Receive, and restarts changed controllers. This changes settings only, never firmware. All enabled tubes must support AudioReactive. A working physical microphone must already be configured on the selected tube.

Sound response

All tubes listen to one selected tube’s microphone. Each group can use a different sound effect and intensity.

A frequency-range filter is not available for these stock effects. WLED’s “Low bin / High bin” controls in certain effects map sound frequency to color; they do not filter triggers. Peak effects share the sender’s peak detection, so separate bass/treble triggers per group cannot be promised.

Use the effect’s sensitivity or intensity control when available. For microphone gain, noise floor and automatic gain, open the selected tube’s AudioReactive settings:

Simple control. Honest limits.

  1. Setup → add tubes and choose Group A or B → Check & save.
  2. Choose a tube microphone → Connect. Controllers may restart briefly.
  3. Select a group, effect and colors → Start lights. Save changes with Apply groups while running.

Fixed, Fade, Pulse, Scroll, Rainbow and Strobe use installed WLED effects. Scroll travels within each tube; it is not BTAir’s fixture-to-fixture chase. Audio flashes are patches of light, not an exact beat strobe. DJ color uses generated colors, not your own beat-triggered color loop.

Color loop → On each beat advances through up to 12 chosen colors when the selected tube reports a sound peak. There is no timer advance; silence or missing audio packets holds the last color. The tube detects the sound; TubeRoom relays color changes to both groups. Keep the Mac awake and the launcher running; Safari may close. WLED detects sound peaks, which may not match every musical beat. Closely spaced triggers within 180 ms are ignored to reduce double hits. Slow or unreachable tubes can miss changes. On a timer remains available and runs entirely on WLED using free preset slots 200–250.

Live samples read actual pixels at up to two updates per second when supported. The layout is a visual arrangement; stock WLED does not use these positions for room-wide effects.

The Mac does no audio analysis or lighting-frame generation. For beat color loops it receives the tube’s peak flags and sends RGB commands. Closing Safari or hiding the tab is fine. Stopping TubeRoom or sleeping the Mac pauses beat color changes at the last color. Other onboard effects keep running. After reopening TubeRoom, click Resume beat relay for an existing beat session. Use Blackout to turn them off; Stop & restore returns each tube to its earlier state. Running playlists from before TubeRoom may need to be restarted in WLED.

No controller firmware is installed or modified. Beat mode needs WLED Audio Sync v2, already present in compatible AudioReactive builds. Existing firmware determines the available effects and microphone support.

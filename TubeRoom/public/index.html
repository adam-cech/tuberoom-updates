WLED, with less friction.

Select bars on the left, pick any shared WLED effect in the middle, then adjust colors and brightness on the right. Sliders apply when you release them. Each control changes only that setting; different looks on unselected bars stay intact.

Effects and palettes are matched by name, even when controllers use different firmware versions. All selected bars must be reachable before normal commands are sent. All off makes a best-effort attempt on every connected bar.

Native WLED effects and microphone processing run on the controllers. TubeRoom does not generate light frames or analyze music. Audio-reactive effects need an audio-enabled WLED build and working microphone setup; configure those through each bar’s WLED link. Shared microphone routing from your previous setup is preserved.

Simultaneous control sends commands together; it does not guarantee animations are phase-locked. This first v3 release focuses on native controls. Custom beat loops and the old room-layout editor are not part of it.

TubeRoom disables normal WLED notification send/receive on bars it controls so a change cannot spill into an unselected group. This persists until changed in WLED Sync settings; audio sync is separate. Hardware configuration, controller presets and segment boundaries are not overwritten.

RGB values are sent directly. If red appears green, correct your LED color order in WLED. Live samples show actual sampled pixels; the default display is only a color guide.

TubeRoom v3

Five bars. One native WLED remote.

Double-click Start-TubeRoom.command, then open TubeRoom in Safari.

Connect your Mac and bars to the same router. Choose Connect bars, save their WLED addresses, then select one bar, a group, or all five. Pick an effect and turn the bars on. Sliders apply when released.

Effects and sound processing run on WLED. You can close the app and the bars keep running. No firmware changes are needed. Advanced hardware and microphone settings are available through each bar’s WLED link.

Already using TubeRoom? Stop & restore in the old app, then use Updates → Check for updates → Install & restart. No new installation is required.
